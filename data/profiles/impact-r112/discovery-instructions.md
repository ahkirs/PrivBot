## How to Run

1. Ensure `discovery-config.properties` is in the profile directory
2. Launch the game client with the PrivBot adapter loaded
3. Log in and perform relevant actions:
   - For combat fields: attack an NPC
   - For inventory fields: pick up or use an item
   - For movement fields: walk around / cross region boundaries
4. RuntimeFieldDiscoverer will observe value changes and persist results
5. Results are written to `mappings/runtime-field-overrides.properties`
